掉盘修复

🔧 修复原理

为什么会掉盘：部分 NVMe（国产公方案高发）在空闲时自行进入 D3cold 深度休眠后唤不醒，PCIe 链路失去响应（内核日志报 CSTS=0xffffffff / Unable to change power state from D3cold to D0），盘从系统里消失，挂载它的存储空间显示「已损坏 / 缺失硬盘」。

本工具做什么：对你在下面列表中自选的盘禁止进入 D3cold 深睡（写 d3cold_allowed=0）——掉盘的直接通道被关闭；浅层省电（PS3/D3hot）保留，盘仍可低功耗待机，只是不会再"睡死"。

生效方式：设置立即生效，同时写入 udev 规则，重启后依旧生效；点「恢复深睡」即还原默认。已掉线的盘（红色标注）重启后即可恢复，建议恢复后先备份数据。
